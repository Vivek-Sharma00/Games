# 🗼 Tower of Hanoi

A Python implementation of the classic mathematical puzzle invented by French mathematician Édouard Lucas in 1883. The puzzle consists of three rods and disks of varying sizes stacked in decreasing diameter.

---

## 🎯 Objective & Rules

### Objective

Move the entire stack of disks from the starting rod (**Source**) to the final rod (**Destination**).

### Rules

1. **One disk at a time:** You can only move the topmost disk of any stack.
2. **Size constraint:** A larger disk can never be placed on top of a smaller disk.
3. **Valid placement:** A disk may only be moved to an empty rod or onto a larger disk.

## 🚀 Running the Game

### Prerequisites

- [Python 3.x](https://www.python.org/downloads/) installed on your system.

### From the Terminal

1. Open your terminal (macOS/Linux) or Command Prompt / PowerShell (Windows).
2. Navigate to the project directory:
   ```bash
   cd "path/to/your/folder"
   ```

## Run the script:

Windows:

```Bash
python main.py
```

macOS / Linux:

```Bash
python3 main.py
```

_(Note: Replace `main.py` with whatever your Python script is actually named, such as `hanoi.py` or `tower_of_hanoi.py`.)_
