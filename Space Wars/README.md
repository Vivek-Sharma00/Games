# 🚀 Space Wars

An arcade 2D space shooter written in Java. Pilot your starship through deep space, dodge enemy hazards, manage your ammunition, and deploy tactical bombs to survive across multiple difficulty levels.

---

## 🎮 Features & Gameplay

- **Difficulty Selection:** Choose between **Easy**, **Medium**, or **Hard** before deploying.
- **Ship Mechanics:** Navigate space hazards (magenta cubes) with fluid flight controls.
- **Resource Management:**
  - **Ammo Pool:** Limited shots with real-time automatic cooldown replenishment.
  - **Screen-Clear Bomb:** Tap `[X]` to detonate a tactical bomb when ready.
- **High Score Tracking:** Keeps track of your run score and personal best.

## 🕹️ Controls

| Action                            | Key Binding           |
| :-------------------------------- | :-------------------- |
| **Move Up / Down / Left / Right** | Arrow Keys / `W`, `S` |
| **Shoot / Primary Fire**          | `Spacebar`            |
| **Deploy Bomb**                   | `X` (when ready)      |
| **Menu / Select**                 | Mouse Click           |

## 🛠️ Installation & Setup

### Prerequisites

- [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/) (version 8 or higher) installed and configured on your `PATH`.

### Running the Game

1. Open your terminal or command prompt.
2. Navigate to the project directory:
   ```bash
   cd "Space Wars"
   ```

### Compile the Java files:

```Bash
javac *.java
```

### Run the main class:

```Bash
java Main
```
