# Falling Block 💀💥

A lightweight 2D arcade game built in Java where you dodge falling obstacles to survive and rack up a high score.

---

## 🎮 Overview

* 🟩 **Player:** Green block
* 🟥 **Obstacles:** Falling red blocks

---

## 🕹️ Controls & Gameplay

### Movement
* **Arrow Keys / A & D:** Move Left ⬅️ / Right ➡️
* Dodge falling blocks to keep your run alive.

![Starting](../Assets/Screenshot%202026-09-03%20114608.png)

### Game Over & Restart
* Press **Enter ↵** to restart after a collision.

![Ending](../Assets/Screenshot%202026-09-03%20112906.png)

## 🛠️ Installation & Setup

### Prerequisites
* [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/) (version 8 or higher) installed and added to your system `PATH`.

### Running the Game

1. Open your terminal or command prompt.
2. Navigate to the project directory:
   ```bash
   cd "path/to/Follingblock"
```
3. Compile the Java source file:

```bash
javac FollingBlock.java
```
4. Launch the game:

```Bash
java FollingBlock
```
*(Note: If your file is strictly named `FollingBlock.java` in your repo, the build commands match that name above. If you rename the `.java` file to `FallingBlock.java`, update the compile and run commands accordingly).*
